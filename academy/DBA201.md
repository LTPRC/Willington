## 知识地图

```text
Java Service
     ↓
Redis
 ├─ 数据结构
 ├─ TTL / 过期
 ├─ Cache Aside
 │   ├─ 穿透
 │   ├─ 击穿
 │   └─ 雪崩
 ├─ DB / Cache 一致性
 ├─ 分布式锁
 └─ 故障保护

Redis 自身：
内存满 → Eviction（淘汰）
重启恢复 → Persistence（持久化）
```

术语：

- **TTL**：Key 还能生存多久；
- **Eviction**：内存达到限制时主动淘汰 Key；
- **Persistence**：把内存数据保存到磁盘以便恢复。
