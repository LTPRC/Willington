# SYS202 - Domain Name Registry Services

返回[Bulletin](./bulletin.md)

域名注册行业的后端服务主线：谁在管 TLD 的注册数据、注册商用什么协议操作它、域名有哪些状态与生命周期、公众怎么查注册数据、注册数据如何托管与合规、以及注册局如何运营 TLD 的权威 DNS。

```text
注册人 → 注册商 ──EPP──→ 注册局（TLD 注册数据库）→ 权威 DNS（对外解析）
                            │
                            ├─ RDAP / WHOIS（对外查询）
                            └─ Data Escrow（数据托管与合规）

RSP 为注册局提供上述全部后端技术能力
```
