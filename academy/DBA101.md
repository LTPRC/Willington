## 课程定位

面向 **Senior Java / Backend Engineer** 技术面试的 MySQL / InnoDB 主线知识库。

目标不是培养 DBA，而是把 MySQL 实战恢复成面试可稳定表达的知识体系：

```text
Java/Spring → SQL → MySQL → InnoDB
                         ├─ B+Tree 索引
                         │   ├─ 聚簇索引
                         │   └─ 二级索引 → 回表/覆盖索引
                         ├─ Transaction
                         │   ├─ MVCC/Undo
                         │   └─ Lock
                         └─ Redo → 崩溃恢复

慢SQL → EXPLAIN → type/key/rows/Extra → SQL/索引优化
```

主打 **InnoDB**；Oracle / 达梦只准备诚实防守；MyISAM / 存储过程 / Trigger 等历史知识全部 Appendix 化。

## 学习优先级

### 【P0】高频主线（必须能稳定口述）

- InnoDB 架构：Server 层 vs 存储引擎层、SQL 执行链路
- B+Tree、聚簇索引、二级索引、回表、覆盖索引、联合索引/最左前缀
- EXPLAIN：type / key / rows / Extra
- 慢 SQL 排查 SOP（不是"加索引"）
- 事务 ACID、隔离级别、MVCC（Undo + ReadView）
- 快照读 vs 当前读、`SELECT ... FOR UPDATE`
- 行锁 / Gap Lock / Next-Key Lock、死锁定位与治理
- redo / undo / binlog 分工、两阶段提交

### 【P1】常见进阶

- Buffer Pool / 脏页 / WAL / 崩溃恢复细节
- 索引下推 ICP、前缀索引、索引选择性
- ORDER BY 原理（全字段排序 vs rowid 排序）、深分页优化
- 倒排索引：Term Dictionary / Posting List / 多 Term 求交
- 唯一约束 / 乐观锁 / 状态机 / 幂等键并发工具箱

### 【P2】低频扩展

- Double Write、Checkpoint、ID 上限行为
- Performance Schema、profiling 历史
- 空间数据索引、自适应哈希索引
- 分库分表（只到概念层，不展开完整理论）

### 【Appendix】历史知识（正确但非当前主线）

- MyISAM 详细对比、Oracle / DB2 对比、范式
- View / Stored Procedure / Trigger / CSV 导入
- 旧版本特性（Query Cache、`innodb_locks_unsafe_for_binlog` 等）

## 推荐复习路径

```text

DBA1011 架构+索引 → DBA1012 事务/MVCC/锁 → DBA1013 EXPLAIN 与优化

第 2 轮（串联成故事）

```
