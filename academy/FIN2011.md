> **本章定位：**Participants。用一次日常消费串起来：你拿一张银行发行的 Visa 卡，在咖啡店买了杯咖啡——这条链路上每个角色都要叫得出名字、说清分工。

## 一次消费串起六个参与方

| 参与方 | 做什么 |
| --- | --- |
| 持卡人 | 你，使用这张卡付款的人 |
| 商户 | 咖啡店，卖东西并收钱的人 |
| 发卡方 | 发行这张卡、管理卡账户的金融机构 |
| 收单方 | 帮商户接受银行卡付款的金融机构 |
| 卡组织 | Visa、Mastercard、银联等，提供交易网络和规则，连接发卡与收单两端 |
| 处理商 | 提供技术处理能力，帮发卡方或收单方处理交易、账户、通知等 |

``` text
持卡人 —刷卡→ 商户 —→ 收单方 —→ 卡组织网络 —→ 发卡方 —→ 持卡人账户
              （处理商可为发卡/收单任意一侧提供技术服务）
```

一句话记住最重要的一条分界：**发卡服务持卡人，收单服务商户。**一家机构可以身兼数角（银行常同时做发卡和收单），但角色本身要分清。

另一个常听到的词：**支付网关**，是商户系统接入支付服务的入口，负责安全地接收和转发支付请求，可能与收单、处理能力集成在同一家服务商里。

## Visa 是发卡银行吗？

不是。Visa 主要提供卡交易网络和规则；通常是合作银行或金融机构发卡、管理持卡人账户。卡上有 Visa 标，只代表这张卡能走 Visa 网络交易，不代表账户里的钱存在 Visa。

## AIX 这类平台负责哪一段？

从公开说明看，AIXPAY 主要提供技术和产品服务，支付、发卡、虚拟资产等金融服务由合作方 dtcpay 提供。所以不能把 AIX 直接理解成发卡银行——它偏处理商/平台侧角色，具体工程职责要看它与发卡合作方怎么分工。注意这是官网公开职责的边界，不能进一步推导成"AIX 所有系统都外包给合作方"。

## 顺带记住两个术语

- **BIN/IIN**：卡号前面的识别号（常见六位或八位），用于识别发卡机构等信息。
- **MCC**：商户类别码（餐饮、酒店等），用于消费限制、风险判断和费用规则。它描述商户类别，不是具体买了哪件商品。

## 本章面试主线

> 一次消费串起六方：持卡人、商户、收单、卡组织、发卡、处理商。核心分界是"发卡服务持卡人、收单服务商户"；Visa 是网络不是银行；AIX 类平台偏技术/产品侧，金融能力来自合作方；BIN 认卡、MCC 认商户。
