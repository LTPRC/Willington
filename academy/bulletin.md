## Syllabus

:mortar_board: SDE101 - [Orientation of SDE](./SDE101.md)

主要讲述如何准备面试、如何预判技术面试和HR面试的常见难题并迎刃而解的相关技巧。

:rocket: SDE121 - [Introduction of Agile](./SDE121.md)

敏捷开发相关知识的概述。

:coffee: CSE271 - [Java Core](./CSE271.md)

Java 语言核心主线：语法基础、面向对象、异常处理、反射、日志、Modern Java 与单元测试，一起玩转 JDK 的一个个细节。

:nut_and_bolt: CSE272 - [Design Patterns](./CSE272.md)

23种常见设计模式以及部分代码实现。

:1234: CSE274 - [Data Structure and Algorithms](./CSE274.md)

数据结构与算法的概念主线辅以 Java 实现。集合、表、字符串、二叉树、数学题/智力题已成篇；链表、排序、图、动态规划、位运算等主题仍在补齐。

:vertical_traffic_light: CSE301 - [Java Virtual Machine](./CSE301.md)

JVM 面试主线：体系结构、类加载与双亲委派、运行时数据区、对象与内存布局、GC 原理与 G1/ZGC 等收集器、执行与编译，历史细节沉入 Appendix。

:closed_lock_with_key: CSE311 - [Multi-thread Programming](./CSE311.md)

操作系统和JVM的多线程并发编程知识。

:floppy_disk: CSE351 - [Java I/O](./CSE351.md)

一条贯穿内核态到应用框架的 I/O 主线：操作系统 I/O 模型、文件描述符与 Socket 通信，Java BIO/NIO/AIO，Netty 线程模型，以及序列化。

:ambulance: CSE381 - [Java Production Troubleshooting & Performance](./CSE381.md)

线上Java服务的故障排查SOP、性能诊断与JVM调优主战手册。

:package: CSE401 - [Spring Ecosystem](./CSE401.md)

从两眼一抹黑到由浅到深逐步理解的Spring框架知识强化。Spring Framework Core、Spring Boot、Spring Web、Spring Cloud、Spring Data Access，历史知识与现代实践并存。

:books: DBA101 - [MySQL](./DBA101.md)

面向 Senior Java 面试的 MySQL / InnoDB 主线：SQL 执行链路、Redo/Undo/Binlog 与崩溃恢复、事务与 MVCC/锁、B+Tree 索引与 EXPLAIN 慢 SQL 优化、倒排索引与全文检索。MyISAM 等历史知识 Appendix 化。

:memo: DBA201 - [Redis](./DBA201.md)

缓存 / NoSQL 主章节：数据结构与 TTL、过期与淘汰策略、Cache Aside 与穿透/击穿/雪崩、DB 与缓存一致性、分布式锁与 Redisson Watchdog、持久化与 Sentinel/Cluster 高可用。

:penguin: SYS151 - [Linux Commands](./SYS151.md)

Linux 日常操作主线：常用目录与命令、网络排查命令，外加 Git 命令与 Shell 编程两门工程必修课。

:whale: SYS181 - [Containerization & Software Delivery](./SYS181.md)

容器化与软件交付：Java 服务从 Source Code 到生产环境的完整链路，以及理解容器所必需的虚拟化、Namespace/cgroup/rootfs 基础。

:globe_with_meridians: SYS201 - [Computer Networks](./SYS201.md)

计算机网络面试主线：体系结构与 HTTP/TCP/IP 三大协议，以及工程上绕不开的 Nginx、缓存与网络安全。

:family: SYS301 - [Distributed Systems](./SYS301.md)

分布式系统基础：不可靠网络下的 Failure 模型、Consistency/Availability、数据复制与多数派、Retry 为何产生 Duplicate、跨服务业务一致性、Consensus，以及 ZooKeeper 协调与分布式锁的正确性。

:incoming_envelope: SYS311 - [Message Queue](./SYS311.md)

探究消息队列的基本原理，分析几种经典消息队列系统。

:atm: SYS401 - [System Design](./SYS401.md)

系统设计的通用方法论与支付金融系统的设计实践。

:chains: SYS411 - [Blockchain](./SYS411.md)

区块链的分布式账本原理、不可篡改机制、共识算法，以及区块链与比特币的区别。
